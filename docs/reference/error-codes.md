This file is generated by `task docs:api` from the errors the packages declare with `auth.NewError`; do not edit it by hand, `task check` fails when it is stale. The same list is [`error-codes.json`](error-codes.json) for tooling and [`error-codes.ts`](error-codes.ts) for a TypeScript frontend. [Errors](../concepts/errors.md) explains when each is returned.
